# Open Talk 溝通圖卡大全

免費開源的失語症溝通圖卡 — 7 板 186 卡。

**[English](README.md)**

**線上試用**：https://thomashuanggogo.github.io/open-talk/（手機或平板開啟即可）

## 這是什麼？

給中風失語患者、語言障礙者的免費溝通輔具。黑白圖示大圖卡、大中文加印尼文註記（台灣病房多為印尼籍看護），點卡中文發聲，可切三種語速。

## 功能

- 🃏 7 板 186 卡（問句、症狀回報、生活照護、外出求助、拒絕、醫療、基本需求）
- 🔊 點卡發聲（中文 TTS，三速可切）
- 🆘 每頁常駐緊急求助鈕
- ✅❌ 是／不是快捷鈕
- ⭐ 常用卡自動置頂
- 📳 震動回饋、🔁 再說一次
- 😊 心情板
- 📱 PWA — 可安裝，離線可用

## 使用方式

免編譯，純靜態檔案，用任何靜態伺服器打開即可（見英文版說明）。
