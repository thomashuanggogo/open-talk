# Open Talk 溝通圖卡大全

Free open-source communication board for aphasia and speech difficulties — 7 boards, 186 cards.

**[繁體中文說明](README.zh-Hant.md)**

**Try it live**: https://thomashuanggogo.github.io/open-talk/ (open in a mobile or tablet browser)

## What is this?

A free communication aid for stroke survivors, aphasia patients, and anyone with speech difficulties. Large cards with black-and-white pictograms, big Chinese text with Indonesian translations (for Indonesian caregivers common in Taiwan), tap-to-speak with three speed settings.

## Features

- 🃏 7 boards, 186 cards (questions, symptoms, daily care, going out, refusal, medical, basic needs)
- 🔊 Tap card to speak (Chinese TTS, 3 speeds)
- 🆘 Emergency button on every page
- ✅❌ Yes / No quick buttons
- ⭐ Frequently used cards auto-pin to top
- 📳 Vibration feedback, 🔁 repeat button
- 😊 Mood board
- 📱 PWA — installable, works offline

## Boards

1. 問句篇 (Questions) — 30 cards
2. 症狀回報篇 (Symptoms) — 50 cards
3. 生活照護篇 (Daily care) — 45 cards
4. 外出求助篇 (Going out) — 15 cards
5. 拒絕篇 (Refusal) — 15 cards
6. 醫療篇 (Medical) — 16 cards
7. 基本需求篇 (Basic needs) — 15 cards

Plus core vocabulary board and caregiver guide.

## Quick start

No build step. Static files:

```
# Serve the folder with any static server, e.g.:
npx serve .

# or
python3 -m http.server 8000
```

Open in a browser. That's it.
